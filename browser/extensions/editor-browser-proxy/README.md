# Editor Browser Proxy

This is a Manifest V3 extension package generated by the Editor Browser's **Install Extension** button.

## Install

1. Click **Install Extension** in the Editor Browser's Proxy Configuration panel.
2. The download is customized for the exact hostname from which the button was clicked.
3. Extract the ZIP.
4. Open `chrome://extensions` (or the equivalent extensions page in your browser).
5. Enable **Developer mode**, choose **Load unpacked**, and select the extracted `editor-browser-proxy` folder.
6. Reload the Editor page.

## Site scoping

The downloaded manifest replaces the content-script match patterns with `*://{{INSTALL_HOST}}/*`. The extension therefore injects its scripts into every matching page and iframe on **{{INSTALL_ORIGIN}}**, including the parent Editor page and the Browser document.

The hostname is written into the downloaded ZIP at generation time. It is not hardcoded in the repository, and the same source package works on production, test deployments, and local development hosts. If the Editor is moved to another domain, download a fresh ZIP from that domain.

The background service worker does not need a list of trusted domains or sender-URL checks: the bridge content script is only injected on the installation host by the generated manifest.

## Design

- `page.js` runs in the main world at `document_start` in every matching frame and replaces that frame's `window.fetch`.
- `bridge.js` runs in the isolated content-script world and relays requests to the service worker.
- `proxy.js` performs direct fetch requests using the extension's `<all_urls>` host permission, allowing cross-origin requests without the page's CORS enforcement.
- The extension does not add or replace Network endpoints. Existing endpoint order and fallback behavior remain intact; the endpoint's captured native `fetch` is routed through the extension.

The manifest's content-script scope is restricted to the installation hostname. The broader `<all_urls>` host permission is still required because requests may target other domains.
