# SoundCraft integration

SoundCraft is pinned as a Git submodule at `editor/previews/vendor/soundcraft-src` from https://github.com/storytold/soundcraft.

- License: dual-licensed MIT OR Apache-2.0. The source submodule retains `LICENSE-MIT`, `LICENSE-APACHE`, `NOTICE` and `ATTRIBUTION.md`.
- Browser target: `apps/soundcraft-web`, compiled to WebAssembly with Trunk.
- Standalone output: `editor/previews/vendor/soundcraft/`, generated by `scripts/build-soundcraft.mjs` and published with the other standalone apps.
- Standalone URL: `https://watermelonkatanadevs.github.io/Editor/editor/previews/vendor/soundcraft/`.

The standalone page works without the Editor. When embedded by the Editor, the iframe adapter routes browser file selection and download-based saves through the single Editor-owned picker in `editor/lib/workspace-picker.js`. Workspace and device files use the same UI; saved sessions and exports are written into the current workspace and mark it dirty. Read-only workspaces cannot be written.

This is the upstream WebAssembly frontend, not the native desktop app. It uses WebGPU with a WebGL2 fallback, uses the browser file picker to open/import, and downloads files when used standalone. It starts with the upstream demo session by default; upstream's `?empty` query flag starts an empty session. SoundCraft is pre-alpha, so keep backup copies of important sessions.
